DNSSEC信頼の連鎖確認ページ

DNSSECの信頼の連鎖を確認するためのテストページです。
URLをクリックすると、「DNSSEC委任状態検証ツール」の画面に遷移します。
なお、以下に列挙するドメイン名はそれぞれゾーン頂点ですが、ドメイン名の先頭に "www." と付けることで、Aレコードでの確認を行うこともできます。

以下では NSECと NSEC3 について確認することができます。

NSEC

  • 失敗パターン：不在証明のカバー不成立 (NSEC の Next Domain Name を所有者名にする) (ドメイン名：missing.cover.mismatch.nsec.rsasha256.dnssec-check.jp)
  • 失敗パターン：NODATA不在証明の不整合 (AAAAを持つドメイン名の NSECビットマップに Aを追加) (ドメイン名：target.type.mismatch.nsec.rsasha256.dnssec-check.jp)

NSEC3

  • 失敗パターン：不在証明のカバー不成立 (NSEC3 の Next Hashed Owner Name を所有者ハッシュにする) (ドメイン名：missing.cover.mismatch.nsec3.rsasha256.dnssec-check.jp)
  • 失敗パターン：NODATA不在証明の不整合 (AAAAを持つドメイン名の NSEC3ビットマップに Aを追加) (ドメイン名：target.type.mismatch.nsec3.rsasha256.dnssec-check.jp)
